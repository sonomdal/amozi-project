# AMOZI

AI 기반 날씨/상황/몸 상태 맞춤 코디 추천 모바일 앱

---

## 📱 프로젝트 소개

AMOZI는 사용자의 현재 날씨, 날짜, 상황, 그리고 컨디션을 기반으로  
AI가 자동으로 패션 코디를 추천해주는 Flutter 기반 모바일 애플리케이션입니다.

Google Gemini AI를 활용하여 스타일링 추천 문장을 생성하고,  
이미지 프롬프트를 통해 시각적인 코디 이미지도 함께 제공합니다.

---

##  주요 기능

### 1. AI 코디 추천
- Google Gemini API 기반 스타일 추천
- 날씨 / 온도 / 상황 / 컨디션 반영
- 한국 패션 스타일 기반 추천

### 2. 날씨 기반 추천
- 현재 위치 기준 날씨 정보 제공
- 기온에 따른 의상 추천

### 3. 상황 선택 기능
- 일상 / 데이트 / 출근 / 캠퍼스 / 운동 / 여행 / 결혼식

### 4. 컨디션 선택
- 보통 / 피곤함 / 활동적 / 감기기운
- 더위 많이 탐 / 추위 많이 탐 등 추가 컨디션 고려

### 5. 옷장 기능
- 사용자 의류 등록 및 관리
- 카테고리별 필터링

### 6. 추천 기록
- 이전 코디 추천 히스토리 저장 및 조회

### 7. 즐겨찾기 기능
- 마음에 드는 코디 저장/삭제

---

##  기술 스택

- Flutter (Dart)
- Google Gemini API (AI 추천)
- SharedPreferences (로그인 상태 저장)
- Flutter Dotenv (.env 환경변수 관리)
- Material Design UI
